## Custom Overrides

The user-provided Swift/Brisk Kanban reference defines the composition: an
edge-to-edge warm white workspace, quiet cool-gray Kanban columns, one compact
workspace sidebar, and softly rounded panels. Blue remains the core accent;
status colors are reserved for task state. No gradients, glass, outer frame,
utility rail, or autoplay animation.

## Layout And Screen Patterns

Product-app header, workspace sidebar, soft-column Kanban, task side sheet,
structured slide editor: outline, 16:9 ACM stage, property inspector. Three slide
types only: title, Markdown information, and one-project live tickets. Automatic
ticket density with pagination past twelve rows. No separate utility rail or outer frame.

## Screen Templates

Project board, personal task list, project directory, presentation editor,
presentation mode, local MVP settings.

## BeUniq Rule Priorities

Clarity over decoration. Visible focus. Compact controls. No excessive pills,
glows, gradients or empty card grids.

## Visual Review Needed

Check desktop and mobile layouts, button and form contrast, empty states,
modal and sheet keyboard interactions.
