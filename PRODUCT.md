# Product

Club OS: локальный MVP управления проектами, задачами и встречами клуба

## Audience

руководители направлений и участники клуба

## Primary Design Goal

ясность и скорость в ежедневной работе

## Voice And Copy Rules

Короткий рабочий русский без маркетинговых обещаний. Каждый текст объясняет
действие или состояние. Не использовать декоративные формулировки.

## References

Linear как ориентир плотности и ясности. Swift/Brisk как визуальный ориентир.
Презентации используют собственный структурированный редактор, без Keystatic.

## Constraints

По умолчанию MVP работает без аккаунтов и сервера, данные сохраняются в localStorage.
Подготовлен HTTP-адаптер для Cloudflare Worker/D1. Пока API не реализован и не подключён,
облачного хранения и Telegram-уведомлений нет. Презентации не владеют копиями задач:
один слайд задач показывает один проект из общего хранилища.

## Do Not Change

Сине-белая палитра, светлая тема, desktop-first рабочий сценарий.
